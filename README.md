# Nikhil Sharma — Portfolio Website

A responsive static portfolio starter built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Contact email and LinkedIn URL are already personalized.
2. GitHub profile was not provided; add it later if you want.
3. Confirm your name, experience duration, skills and project descriptions.
4. Keep project descriptions generic unless you have permission to disclose client/employer details.
5. Do not publish company source code, credentials, customer data or internal architecture.

## GitHub Pages quick publish
1. Sign in to GitHub and create a new **public** repository named `nikhil-sharma-portfolio` (or use `<your-username>.github.io` for a user site).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (README can also be uploaded).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to finish deploying. The repository's Pages settings will show the live URL.

For a project repository, the URL is usually `https://<your-username>.github.io/nikhil-sharma-portfolio/`. For a user-site repository named `<your-username>.github.io`, the URL is `https://<your-username>.github.io/`.

## Deploy
This is a static site and can be hosted on GitHub Pages, Netlify or Vercel. Upload the contents of this folder to a repository or hosting project and enable static-site deployment. A public URL is not created by this package itself.
